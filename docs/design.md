设计规范（低保真 → 中保真）

视觉风格
- 主色：淡蓝 `#5DADE2`
- 辅助色：深灰 `#333333`，中灰 `#666666`，浅灰 `#EEEEEE`
- 字体：系统 UI 字体（桌面端首选）

布局与响应
- 桌面优先（宽屏 1280px 及以上）
- 组件：表格行高 40px，表单控件最小触控目标 40x40px

组件规范
- 表格：支持行内编辑、批量导入、导出按钮显著可见
- 预警提醒：使用颜色 + 文本说明（红色错误、黄色警告、蓝色信息）
- 模板语言切换：在发货页面提供明显的语言下拉与面单预览

可访问性
- 对比度符合 WCAG AA
- 键盘可导航主要操作

交互说明
- 保存/提交操作使用幂等设计：后端返回唯一任务 ID，前端展示执行结果
- 批量操作需异步执行并在完成后通过通知/任务列表告知用户
