### 2.2 模块划分

| 模块 | 职责 | 核心功能 |
|-----|------|---------|
| materials | 物料档案管理 | 物料CRUD、CVA-ABC分类 |
| production | 生产成本核算 | 约当产量法、成本分摊 |
| purchase | 采购管理 | 采购订单、发票校验 |
| inventory | 仓库管理 | 出入库、盘点、库存变动 |
| compliance | 合规预警 | 税率校验、税号管理、预警规则 |
| crossborder | 跨境合规 | HS编码、税费计算、多币种 |

## 四、关键设计

### 4.1 数据库连接配置

```python
# database.py 设计要点
- 使用 SQLAlchemy 2.0 异步连接
- 连接池配置：最大连接数 20，最小空闲 5
- 自动重试机制
```

### 4.2 API响应格式

所有API响应统一格式：
```json
{
  "success": true,
  "data": {},
  "message": "",
  "error_code": null,
  "timestamp": "2026-05-18T10:30:00Z"
}
```

### 4.3 错误处理

| 错误码 | 含义 | HTTP状态码 |
|-------|------|-----------|
| 40001 | 参数校验失败 | 400 |
| 40002 | 资源不存在 | 404 |
| 40003 | 业务规则校验失败 | 400 |
| 50001 | 数据库操作失败 | 500 |
| 50002 | 外部服务调用失败 | 503 |
