## 开发规范

### 代码提交规范
- 提交信息格式：`[模块] 描述`
  - 示例：`[成本核算] 完成约当产量算法实现`
  - 示例：`[合规] 添加税率校验预警`

### 每日工作要求
1. 开始工作前创建当日日志
2. 提交代码时关联日志记录
3. 下班前更新日志中的完成事项

### 代码审查
- 关键模块需双人review
- 算法实现需通过测试用例验证
